# 分发包许可证交付设计

## 目标

将项目根目录 `LICENSE` 作为唯一许可证源文件，确保默认发布流程生成的各类交付物都能随附同一份 Apache License 2.0 文本。

## 交付范围

- 发布目录根部生成 `dist\LICENSE`，覆盖客户端安装包、服务端安装包和 Android APK 的整体交付。
- Windows 客户端现场重打包目录生成 `dist\LSYL Tunnel Client\LICENSE`。
- Windows 客户端和服务端安装器将 `LICENSE` 安装到各自程序根目录。
- Android APK 不内置重复副本，使用同目录发布包中的 `dist\LICENSE` 完成交付。

## 实现约束

- 不维护许可证正文副本；临时包和发布目录都从项目根 `LICENSE` 复制。
- 不启用安装器许可证确认页面，不改变现有安装交互。
- 不调整 WinDivert 和 Inno Setup 的第三方许可证处理方式。
- 发布校验和 Windows 自检必须检查许可证存在，并校验内容与项目根文件完全一致。

## 验证

- 先让新增的自检断言因许可证缺失而失败。
- 修改打包链路后重新执行自检，确认客户端包、服务端包和最终发布目录均通过内容一致性检查。
- 执行 `git diff --check`，确保脚本和文档没有格式错误。
