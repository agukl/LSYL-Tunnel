# Android 配置操作区设计

## 目标

优化 Android 客户端页面底部的配置操作区，并防止误删配置。

## 布局

- `导入配置`、`编辑转发`、`删除配置`位于同一行。
- 可用宽度按 `50% / 25% / 25%` 分配，按钮之间保留统一间距。
- `删除配置`继续使用危险操作配色，其余按钮沿用现有次要操作样式。
- 沿用当前运行状态控制：隧道连接期间，配置操作保持禁用。

## 删除流程

1. 点击`删除配置`后，首次确认是否删除当前配置。
2. 首次确认后弹出第二次确认，明确说明删除后无法恢复，需要重新导入管理员配置。
3. 只有第二次点击`确认删除`才执行现有删除逻辑；任意一步取消均不修改配置和运行状态。

## 边界

- 不改变配置文件格式、导入流程、转发编辑逻辑和服务端协议。
- 不增加手机系统设置、电池管理或厂商相关提示。

## 验证

- 单元测试覆盖删除确认流程的两阶段状态转换和取消路径。
- Android 单元测试与 APK 构建通过。
- ADB 真机检查三个按钮同排、宽度比例和两次确认交互。
